AI uchun API

Basepoint doskalariga tashqi skript yoki AI agent orqali ulanish uchun qoʻllanma. Barcha javoblar JSON koʻrinishida qaytadi.

https://api.basepoint.app/v1 REST JSON 100 soʻrov / daqiqa

1. Autentifikatsiya

Har bir soʻrovda API kalitini Authorization sarlavhasida yuboring. Kalit Sozlamalar boʻlimidan olinadi va faqat bir marta koʻrsatiladi.

curl https://api.basepoint.app/v1/projects -H "Authorization: Bearer bp_live_7f3a..."

2. Endpointlar

GET/projectsLoyihalar roʻyxati
POST/projectsYangi loyiha yaratish
GET/projects/{id}/tasksLoyihadagi vazifalar
POST/projects/{id}/tasksVazifa qoʻshish
GET/tasks/{id}Bitta vazifa
PATCH/tasks/{id}Vazifani yangilash
DELETE/tasks/{id}Vazifani oʻchirish
GET/statusesUstunlar roʻyxati

3. Vazifa yaratish

Yangi vazifa status maydonida koʻrsatilgan ustunga tushadi. Status berilmasa, vazifa goyalar ustuniga qoʻshiladi.

curl -X POST https://api.basepoint.app/v1/projects/prj_asosiy/tasks -H "Authorization: Bearer bp_live_7f3a..." -H "Content-Type: application/json" -d '{"title": "Northwind bilan demo", "status": "rejalashtirilgan"}'

Javob:

{
  "id": "tsk_9d21",
  "title": "Northwind bilan demo",
  "status": "rejalashtirilgan",
  "project_id": "prj_asosiy",
  "position": 3,
  "created_at": "2026-09-28T09:14:00Z"
}

4. Statuslar (ustunlar)

Doskadagi ustunlar quyidagi kalitlar bilan ifodalanadi:

muhokamada        Muhokamaga olinganlar
rejalashtirilgan  Rejalashtirilgan
qilingan          Qilingan
bekor_qilingan    Bekor qilingan
goyalar           Gʻoyalar

Vazifani boshqa ustunga koʻchirish uchun status maydonini yangilang:

curl -X PATCH https://api.basepoint.app/v1/tasks/tsk_9d21 -H "Authorization: Bearer bp_live_7f3a..." -H "Content-Type: application/json" -d '{"status": "qilingan"}'

5. Xatolar

Xatolik yuz berganda HTTP kodi bilan birga error obyekti qaytadi.

{
  "error": {
    "code": "task_not_found",
    "message": "tsk_0000 topilmadi",
    "status": 404
  }
}

401 — kalit notoʻgʻri · 404 — obyekt topilmadi · 422 — maydon xato toʻldirilgan · 429 — limit oshdi.

6. AI agent uchun tezkor start

Agentga quyidagi ketma-ketlikni bering: loyihalarni oling, kerakligini tanlang, vazifalarni oʻqing yoki yangisini yarating.

1. GET  /projects                      -> loyiha id sini aniqlang
2. GET  /projects/{id}/tasks?status=goyalar
3. POST /projects/{id}/tasks           -> yangi vazifa
4. PATCH /tasks/{id}                   -> ustunni oʻzgartirish

Agent vositasi (tool) sifatida ulash uchun tavsif namunasi:

{
  "name": "basepoint_create_task",
  "description": "Basepoint doskasida yangi vazifa yaratadi",
  "input_schema": {
    "type": "object",
    "properties": {
      "project_id": { "type": "string" },
      "title":      { "type": "string" },
      "status":     { "type": "string", "enum": ["goyalar", "rejalashtirilgan", "muhokamada", "qilingan", "bekor_qilingan"] }
    },
    "required": ["project_id", "title"]
  }
}
